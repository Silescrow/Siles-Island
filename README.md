# SILES ISLAND

Survival-Spiel im Browser: Siles wacht auf einer Insel auf, sammelt, baut und zähmt Dinos.

| Ordner | Inhalt |
|---|---|
| `01_Charakter` | Siles (Bilder und 3D-Modelle mit Animationen) |
| `02_Dinos` | Raptor, Pachy, Sattel |
| `03_Waffen_Werkzeuge` | Werkzeuge und Waffen (3D-Modell, Bild, Icon) |
| `04_Essen` | Fleisch roh und gebraten |
| `05_Natur` | Bäume, Büsche, Felsen, Erz, Kristall, Vulkan, Boden-Texturen |
| `06_Bauteile` | Haus, Zaun, Tor, Floß; `Alt/` (alte Strohteile), `Geplant/` |
| `07_Einrichtung` | Bett, Lagerfeuer, Werkbank, Todes-Rucksack |
| `08_Musik` | Hauptmenü, Tag, Nacht, Kampf; `Ungenutzt/` |
| `09_Hauptmenue` | Logo, Cover, Hauptmenü, Ladebildschirm (mit Entwürfen und Varianten) |
| `10_Spielversionen` | alle Versionen `Siles_Island_v1.0` bis heute (in 0.1-Schritten) |

Zum Spielen reicht die neueste Datei in `10_Spielversionen`.
